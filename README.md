# Store Chain Sales forecasting with Machine Learning

Created and evaluated multiple forecasting models (Prophet, XGBoost, CatBoost, LightGBM) to predict daily sales for a restaurant chain across 163 locations, using daily iterative forecasting 
Cleaned the data by performing data cleanliness checks, handling missing values, and engineering relevant features such as cyclical date encodings and sliding window lags to improve model accuracy
Improved relevant error metric (symmetric mean absolute percentage error) by 15% over baseline through modeling
